# fit-extremes

Eight combinations verify none/scale-down with boxes smaller and larger than the image and opposite object positions. Scale-down never enlarges the intrinsic image.

2 sizes × 2 fit modes × 2 positions. Pixelated rendering makes sampling and intrinsic size visible without interpolation blur.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
