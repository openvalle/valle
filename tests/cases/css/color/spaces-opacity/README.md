# spaces-opacity

24 solid-region controls cross all supported color() RGB/XYZ spaces and Lab-family colors with full/half opacity in SDR output.

12 color forms × 2 opacities. Solid interiors isolate conversion and alpha from antialiasing; color input gamut does not change the output color space.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
