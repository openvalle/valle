# three-layer-composites

Eight controls cross all four mask-composite operators with alpha/luminance for three asymmetric layers, exposing list repetition, composition order and mask interpretation.

4 composite modes × 2 mask modes. Black, white and middle gray provide explicit alpha/luminance controls; three layers distinguish left/right composition order.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
