# backdrop-roots

Twelve nested backdrop controls cross root-forming properties with a second backdrop read. Transparent group content exposes whether sampling leaks through an ancestor root.

6 ancestor controls × 2 nested reads. Isolation is a stacking context but does not by itself create a backdrop root. Filter, opacity, mask and clip are independently controlled. Browser disagreement must be recorded rather than resolved by majority vote.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
