# blend-families

32 controls cross every supported CSS blend mode with absent/inverted backdrop and a translucent child. Solid regions separate compositing formulas from edge antialiasing.

16 blend modes × 2 backdrop filters. Normal and no-filter controls distinguish source-over from backdrop-aware blending. All colors are opaque sRGB except the child opacity.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
