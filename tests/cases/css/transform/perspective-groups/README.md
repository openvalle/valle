# perspective-groups

Twelve perspective controls cross perspective origin, preserve-3d/flat and an overflow grouping property. Nested Z translations expose flattening and projection order.

3 perspective origins × 2 transform styles × 2 overflow modes. Overflow hidden forces the group flat even when preserve-3d is authored.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
