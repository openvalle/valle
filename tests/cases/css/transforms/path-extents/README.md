# path-extents

Sixteen open-path controls cross before/start/middle/after distances, anchor and tangent direction. Out-of-range distance clamps to endpoints while reverse flips orientation.

4 distances × 2 anchors × 2 rotations. Explicit absolute positioning and nonzero containing blocks avoid the previously recorded browser zero-reference-box case.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
