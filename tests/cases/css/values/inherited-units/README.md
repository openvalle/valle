# inherited-units

24 combinations cross inherited font size, em/rem/px/percentage lengths and writing mode. Physical percentage width remains relative to the 160px containing width.

2 fonts × 4 length forms × 3 writing modes. em uses the inherited font size; rem is 16px; 25% of 160px is 40px. Padding is one quarter of the inherited font size.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
