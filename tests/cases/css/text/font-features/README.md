# font-features

44 keyword controls exercise kerning and every accepted font-variant longhand value. Each selected feature is paired with the same font and text at its default setting.

Feature keywords are listed explicitly with their control text. Noto Sans contains liga, small-cap and numeric substitutions; Noto Sans SC contains width/ruby/historical features. Unsupported font features must safely retain the default glyphs. This distinguishes accepted CSS from actual substitutions provided by a font.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
