# alignment-matrix

Full product: 3 inline display modes × 4 alignment choices = 12.

The same 40×24 border box appears beside a smaller superscript Span. Parent
paragraph dimensions are independently asserted; box placement is checked by
browser images. The broader geometry/seek matrix separately crosses writing
modes and directions with these display and alignment choices.

Fonts are pinned. Browser images are compared and reviewed before selecting a
baseline. Rasterization allowances must not hide missing lines or shifted boxes.
