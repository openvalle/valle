# wrap-matrix

Full product: 2 widths × 3 whitespace modes × 2 word-break values × 2 overflow-wrap values = 24.

The pinned Noto Sans M advance is 907 font units at 1000 units/em. Four Ms
need 87.072px at 24px. Normal unbreakable text remains one line; break-all or
anywhere permits splitting when wrapping is enabled. Baselines are 25px below
the line top with 32px leading, matching the existing pinned-font controls.

Fonts are pinned. Browser images are compared and reviewed before selecting a
baseline. Rasterization allowances must not hide missing lines or shifted boxes.
