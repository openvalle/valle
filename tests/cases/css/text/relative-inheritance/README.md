# relative-inheritance

Eight parent size/weight controls exercise larger/smaller and bolder/lighter inheritance in adjacent runs and at weight-range boundaries.

4 weights × 2 sizes. Relative sizes use the documented 1.2 scale; weight transitions use the CSS relative-weight table.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
