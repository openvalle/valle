# axes-synthesis

Eight combinations cross variable axes, synthesis permission and x-height adjustment through a smaller/bolder nested run. Native variable axes remain active when synthesis is disabled.

2 axis settings × 2 synthesis permissions × 2 size adjustments. The font declares wght 100–900 and wdth 62.5–100. Explicit axes override automatic weight/stretch selection; nested relative values must preserve inherited axes.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
