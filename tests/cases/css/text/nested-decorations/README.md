# nested-decorations

Four nested decoration controls combine wrapping, mixed sizes, propagated outer decorations and an independently colored inner double underline.

2 outer decoration sets × 2 clipping modes. Decorations propagate through differently styled descendants; changing child color must not recolor an ancestor decoration.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
