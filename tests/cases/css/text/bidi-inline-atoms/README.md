# bidi-inline-atoms

18 combinations cross bidi direction, writing mode and atomic inline alignment with explicitly declared Latin, Hebrew and Han fonts and a decorated smaller run.

3 writing modes × 2 directions × 3 alignments. The fixed font list makes fallback deterministic; all three scripts have declared fonts. Inline atom ordering and physical placement are checked in pixels.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
