# text-effects

Eight combinations verify text-clipped repeated gradients with background positioning, blur and rotation.

2 filters × 2 transforms × 2 background positions. Fixed Noto Sans outlines establish the clip; a transparent text fill must not erase the clipped background.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
