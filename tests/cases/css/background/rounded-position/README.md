# rounded-position

Six controls position round-resized tiles using their final size, with explicit left/center/right and top/center/bottom positions.

3 positions × 2 rounded axes. The 28px width becomes 25px; centered X is (100−25)/2=37.5px. The 22px height becomes 76/3px; centered Y is (76−76/3)/2. CSS positioning follows resizing, even where browser captures differ.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
