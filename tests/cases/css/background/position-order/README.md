# position-order

Eight controls cross background-position shorthand order with independent X/Y lists of different lengths. Later declarations win on each axis and shorter lists repeat.

2 declaration orders × 2 X lists × 2 Y lists. Two solid layers distinguish each image placement without gradient antialiasing.

The listed inputs are permanent. Browser HTML uses ordinary CSS and does not
consume Valle layout results. Review the three browser images and native
difference images before accepting the baseline.
